# Commands

Slash commands drive the horse-sense SDLC workflow. Invoke them inside Claude Code by typing `/horse:<command>`.

| Command | Description |
|---|---|
| [`/horse:guide`](#guide) | Kick off the SDLC trail: requirements → design → planning → implementation |
| [`/horse:plan`](#plan) | Create or update the project plan and sprint backlog |
| [`/horse:arch`](#arch) | Design system architecture, generate diagrams and ADRs |
| [`/horse:implement`](#implement) | Implement a user story with a TDD workflow |
| [`/horse:test`](#test) | Create and run tests with coverage reporting |
| [`/horse:review`](#review) | Code review against project standards |
| [`/horse:deploy`](#deploy) | Deploy to staging or production with pre-flight checks |
| [`/horse:sprint`](#sprint) | Plan and manage a sprint |
| [`/horse:retrospective`](#retrospective) | Facilitate a sprint retrospective |
