# Agents

Agents are specialized role personas. Each agent composes skills and references rules appropriate to its role. Agents are auto-discovered by Claude Code and available via `/agents`.

| Agent | Best For |
|---|---|
| [planner](#planner) | Requirements, roadmaps, sprint planning |
| [architect](#architect) | System design, tech selection, ADRs |
| [developer](#developer) | Implementation, debugging, refactoring |
| [tester](#tester) | Test strategy, coverage, security scans |
| [reviewer](#reviewer) | Code review, security, performance |
| [scout](#scout) | Research spikes, technology evaluation |
| [trainer](#trainer) | Artifact quality auditing, process compliance |
