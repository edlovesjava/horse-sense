# Templates

Templates are document scaffolds referenced by commands and skills. They are not auto-discovered — commands and skills copy or reference them explicitly.

Each template lives in `horse/templates/` and is linked below to its source on GitHub.

| Template | Used By |
|---|---|
| [horse_config.md](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/horse_config.md) | `/horse:guide` — SDLC workflow config scaffold |
| [project_plan.md](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/project_plan.md) | `/horse:plan` — project plan scaffold |
| [requirements_doc.md](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/requirements_doc.md) | `/horse:plan` (monolith mode) |
| [requirements_index.md](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/requirements_index.md) | `/horse:plan` (per-story mode) |
| [user_story.md](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/user_story.md) | Per-story requirements files |
| [architecture_doc.md](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/architecture_doc.md) | `/horse:arch` — architecture scaffold |
| [sprint_plan.md](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/sprint_plan.md) | `/horse:sprint` — sprint plan scaffold |
| [spike_report.md](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/spike_report.md) | scout skill — research spike report |
| [ci.yml](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/ci.yml) | GitHub Actions CI workflow template (Python + TypeScript matrix) |
| [config.example.python.json](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/config.example.python.json) | `.claude/config.json` example for Python |
| [config.example.typescript.json](https://github.com/edlovesjava/horse-sense/blob/main/horse/templates/config.example.typescript.json) | `.claude/config.json` example for TypeScript |
