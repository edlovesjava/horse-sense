# Skills

Skills are model-invoked step-by-step guides. They adapt to your project's language and toolchain by reading `.claude/config.json`.

| Skill | Description |
|---|---|
| [requirements-analysis](#requirements-analysis) | Elicit, document, and validate requirements |
| [architecture-design](#architecture-design) | Design systems, select technologies, create ADRs |
| [implementation](#implementation) | TDD workflow with language-appropriate tooling |
| [testing](#testing) | Test pyramid strategy with coverage enforcement |
| [deployment](#deployment) | Docker, CI/CD, runbooks, and rollback procedures |
| [python-venv](#python-venv) | Python virtual environment setup |
| [typescript-setup](#typescript-setup) | TypeScript / Node.js project setup |
| [pr-review](#pr-review) | Review a PR using `gh` CLI, post inline comments |
| [pr-fix](#pr-fix) | Triage and address PR review comments |
| [scout](#scout) | Conduct a timeboxed research spike and produce a report |
